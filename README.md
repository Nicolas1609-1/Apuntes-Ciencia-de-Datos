# Ciencia de Datos

Este repositorio reúne trabajos y ejercicios de clase sobre aprendizaje automático, redes neuronales y procesamiento de imágenes. Incluye notebooks para estudiar los modelos paso a paso y pequeñas aplicaciones para probarlos.

## Redes neuronales

En [Perceptron Trabajo en Clase](Perceptron%20Trabajo%20en%20Clase/Actividades/README.md) están las prácticas de perceptrón con scikit-learn, redes densas con Keras y ejercicios de clasificación. También hay notebooks sobre Fashion-MNIST y un modelo para clasificar células.

La aplicación de prendas permite dibujar una silueta y usar un modelo entrenado con Fashion-MNIST para predecir a qué categoría pertenece, como camiseta, pantalón, vestido o calzado.

## Procesamiento de imágenes

El script `Huevos.py` crea versiones sintéticas de imágenes de huevos con grietas. Las imágenes resultantes se guardan como material para ejercicios de visión por computador y clasificación.

La carpeta [convoluciones](https://github.com/adiacla/convoluciones) contiene una demo en HTML y JavaScript para observar cómo los filtros y las convoluciones modifican una imagen o una captura de cámara.

## Apuntes y notebooks

Los notebooks cubren temas como el perceptrón, redes densas, clasificación y redes convolucionales. Hay más cuadernos y material del curso en [Apuntes-Ciencia-de-Datos](https://github.com/adiacla/Apuntes-Ciencia-de-Datos).

Los notebooks se pueden abrir en VS Code con la extensión de Jupyter. Cada carpeta incluye sus propios archivos y dependencias; revisa su README o `requirements.txt` para más información.
